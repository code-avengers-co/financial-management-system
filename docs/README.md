# Documentação do projeto

Esta pasta reúne os artefatos de planejamento e acompanhamento do Sistema Web de Gestão Financeira Pessoal.

## Pré-projeto

O diretório [`pre-projeto`](pre-projeto/) contém:

- o relatório editável com visão, objetivos, escopo, requisitos, entidades, regras de negócio, riscos e roadmap;
- o diagrama de classes simplificado da Etapa 1;
- o fluxo de lançamento financeiro e verificação de orçamento;
- o mapa de navegação das telas;
- a arquitetura em camadas proposta.

## Convenção para documentos futuros

À medida que o projeto avançar, a documentação pode ser organizada assim:

```text
docs/
├── pre-projeto/
├── banco-de-dados/
├── seguranca/
├── relatorios/
└── apresentacao/
```

Novas decisões de escopo ou alterações solicitadas pelo professor devem ser registradas junto à etapa correspondente.
